# RobotMCP Example Project

This is a minimal Robot Framework project scaffold created for `#robotmcp` usage.

Quick start

1. Create a virtual environment and activate it.
2. Install dependencies:

```bash
pip install -r requirements.txt
```

3. Run tests:

```bash
robot tests
```

Project layout

- `tests/` — example Robot test suites
- `resources/` — shared resource files and keywords
